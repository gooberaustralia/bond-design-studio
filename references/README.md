# Client reference files

Files in `references/documents/` are for **AI/build context** (brand guides, copy decks). They are optional on production: add `references/` to `.vercelignore` to exclude from deploy.

Files in `references/inspiration/` are **saved design templates** (screenshots from Goober). **Design reference only** — do not link them from HTML as `<img src>` on the live site.

**Site photos** belong in `assets/images/` (uploaded via Goober) and deploy with the site at `/assets/images/...`.
